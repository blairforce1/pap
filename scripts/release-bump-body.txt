## How to revert

Revert the merge. A release bump that is open, overtaken on main or left by an exit 3 is closed with its branch, as the owner's act (`gh pr close <n> --delete-branch`). Then `mise run tidy`, and run the bump again. A release already cut from a bump stays: ship a later version rather than delete it. Outside git: none.
